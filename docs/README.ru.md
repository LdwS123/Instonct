---

**Instonct** — это open-source, self-hosted **персональный ИИ-агент**. Вы пишете ему в **WhatsApp или Telegram**
(текстом или голосовым сообщением), и он делает дела: читает и составляет черновики писем, управляет вашим Google Календарём, ставит напоминания
и задачи, ходит по сайтам и заполняет веб-формы, превращает страницу в CSV, следит за страницей и сообщает вам, когда она
меняется, включает музыку и даже выполняет команды оболочки на машине, где он живёт.

Он работает круглосуточно на **Mac mini 2010 года** (Core 2 Duo, 4,6 ГБ ОЗУ, Lubuntu). Если он тянет на этом железе, то потянет
почти на чём угодно: на Raspberry Pi, старом ноутбуке, дешёвом VPS.

## Что он умеет

| Область | Что можно сказать |
|---|---|
| **Почта** | «Есть сегодня важные письма?», «Ответь Паулю, скажи, что я приду». Отправляет только после того, как вы нажмёте **Да**. |
| **Календарь** | «Поставь стоматолога на четверг в 15:00», «Добавь Google Meet с Мари». Предупреждает о конфликтах. |
| **Браузер** | «Зайди на news.ycombinator.com и дай мне CSV с 30 лучшими заголовками», «Войди на сайт моего спортзала». |
| **Слежение** | «Скажи, когда на этой странице появится *в наличии*». Проверяет каждые 10+ минут, пишет только при изменении. |
| **Память** | Запоминает ваши предпочтения навсегда и учится, когда вы его поправляете. |
| **Рутины** | Утренняя сводка (повестка дня, почта, погода, ваш приоритет №1), напоминания, задачи по расписанию. |
| **Голос** | Принимает голосовые сообщения (Whisper), отвечает голосовыми сообщениями или вслух. |
| **Файлы** | Отправьте ему фото, PDF или CSV и задайте вопрос о них. Он тоже может присылать файлы. |
| **Дом** | Музыка, пульт ТВ, громкость, состояние сервера, команды оболочки (с подтверждением). |
| **Любой язык** | Отвечает на том языке, на котором вы пишете или говорите. |

У него есть и характер: короткие ответы, одна чёткая рекомендация, никакой воды. Его зовут *Стив*.

## Выберите свой «мозг»: любая модель, любой провайдер

Instonct работает с любым **OpenAI-совместимым API**, так что вы не привязаны к одной компании. Достаточно трёх строк в `.env`:

```bash
LLM_BASE_URL=https://api.groq.com/openai/v1     # по умолчанию
LLM_API_KEY=...
LLM_MODELS=openai/gpt-oss-120b,openai/gpt-oss-20b,qwen/qwen3.8-27b    # пробуются в этом порядке
```

| Провайдер | `LLM_BASE_URL` |
|---|---|
| Groq (по умолчанию, быстрый, есть бесплатный тариф) | `https://api.groq.com/openai/v1` |
| OpenRouter (сотни моделей) | `https://openrouter.ai/api/v1` |
| OpenAI | `https://api.openai.com/v1` |
| Together AI | `https://api.together.xyz/v1` |
| Mistral | `https://api.mistral.ai/v1` |
| Cerebras | `https://api.cerebras.ai/v1` |
| Ollama / LM Studio (100% локально, без ключа) | `http://localhost:11434/v1` |

Указывайте названия моделей точно так, как их пишет ваш провайдер, и выбирайте модели с поддержкой вызова инструментов (tool calling).

- **Переключение на лету**: отправьте `/model`, чтобы увидеть список, `/model 2`, чтобы использовать модель номер 2 первой, `/model auto`, чтобы вернуться обратно.
- **Автоматический резерв**: если у модели исчерпан лимит запросов или она недоступна, следующая подхватывает работу сама.
- **Необязательная подстраховка**: добавьте `GEMINI_API_KEY`, и Google Gemini ответит, когда ваш основной провайдер недоступен (а ещё он читает изображения).
  Без него Instonct прекрасно работает и с одним провайдером.
- **Голосовые сообщения**: расшифровываются через Whisper API (`STT_MODEL`, `STT_BASE_URL`, `STT_LANGUAGE`, по умолчанию тот же провайдер).

## WhatsApp или Telegram?

Работают оба, одновременно, с одним и тем же «мозгом», памятью и правилами безопасности.

| | Telegram | WhatsApp |
|---|---|---|
| Настройка | 2 минуты с @BotFather | Аккаунт разработчика Meta, номер, токен (около 30 минут) |
| Нужен публичный адрес | Нет (бот обращается сам) | Да (Meta обращается к вашему серверу: подойдёт Tailscale Funnel) |
| Кнопки Да / Нет, голос, файлы | Да | Да |
| Клавиатура пульта ТВ, сохранение паролей через `/site` | Да | Только в Telegram (так задумано, см. «Безопасность») |
| Сообщения, которые бот отправляет сам (напоминания) | Всегда | Только в течение 24 ч после вашего последнего сообщения |
| Уже есть на телефоне | Возможно | Почти наверняка |

**Честный совет**: начните с Telegram, он проще и безопаснее. Добавьте WhatsApp, когда захотите общаться с ним в приложении,
которым вы и так пользуетесь каждый день. Instonct использует **официальный WhatsApp Cloud API** от Meta, а не неофициальную библиотеку, поэтому
риска блокировки вашего номера нет.

### Подключение WhatsApp (необязательно)

1. На [developers.facebook.com](https://developers.facebook.com) создайте приложение, добавьте продукт **WhatsApp** и запишите
   **Phone number ID**. Бесплатный тестовый номер подойдёт, чтобы попробовать; позже можно привязать свой собственный номер.
2. Создайте постоянный токен доступа (токен *System User* в настройках Meta Business) и скопируйте **App secret**
   (настройки приложения, раздел Basic).
3. Добавьте в `~/bots/.env` (ваш собственный номер: только цифры, сначала код страны, без `+`):
   ```bash
   WA_TOKEN=...
   WA_PHONE_ID=...
   WA_APP_SECRET=...
   WA_VERIFY_TOKEN=any-secret-string-you-invent
   WA_OWNER=33612345678
   ```
4. Дайте Meta публичный HTTPS-адрес для локального вебхука (порт 8088, привязан к `127.0.0.1`). С Tailscale:
   `sudo tailscale funnel --bg 8088`. Команда выведет адрес вида `https://<machine>.<tailnet>.ts.net`.
5. В настройках WhatsApp вашего приложения Meta укажите этот адрес как **Callback URL** вебхука, а в поле **Verify token** —
   ваш `WA_VERIFY_TOKEN`, затем подпишитесь на поле **messages**.
6. Перезапустите бота (`sudo systemctl restart bot-telegram`) и напишите на свой номер WhatsApp.

Каждый входящий вызов отклоняется, если его `X-Hub-Signature-256` не совпадает с секретом вашего приложения, а отвечает бот только на номера из
`WA_OWNER`. Названия элементов в панели Meta время от времени меняются; суть остаётся прежней.
Версия API по умолчанию — `v23.0`; переопределите её через `WA_API_VERSION`, если Meta её отключит.

## Instinct AI и Instonct

| | Instinct AI | Instonct |
|---|---|---|
| Доступ | Только по приглашениям (по данным прессы) | Клонируйте репозиторий и запускайте |
| Где работает | В облаке компании | **На вашей собственной машине** |
| Ваши данные | Переданы стартапу | Остаются на вашем устройстве (Redis + локальные файлы) |
| Как с ним общаться | Текст, телефон, WhatsApp (по данным прессы) | WhatsApp или Telegram, текстом или голосом |
| Модели | Выбраны за вас | **Любой OpenAI-совместимый провайдер**, переключение через `/model` |
| Стоимость | Не разглашается | Работают бесплатные тарифы (Groq, Gemini); или полностью локально с Ollama |
| Исходный код | Закрыт | **Прямо здесь** |

Instinct AI — настоящий продукт, созданный командой с финансированием; Instonct — проект одного человека, из выходного дня ставший ежедневным инструментом.
Выбирайте Instonct, если хотите ту же идею, но с руками на руле.

## Как это работает

- **Мозг**: любая OpenAI-совместимая модель (по умолчанию Groq `gpt-oss-120b` / `20b` с адаптивной глубиной рассуждений), опциональный резерв на Gemini.
- **Инструменты**: модель вызывает около 35 инструментов (почта, календарь, браузер, файлы, музыка, ТВ, оболочка...). Смотрите `TOOLS` в [`bots/telegram-search/bot.py`](../bots/telegram-search/bot.py).
- **Браузер**: [Lightpanda](https://github.com/lightpanda-io/browser), крошечный headless-браузер (~25 МБ ОЗУ), который работает даже на процессоре 2010 года. Смотрите [`webagent.py`](../bots/telegram-search/webagent.py).
- **Каналы**: Telegram через long polling (без открытого порта), WhatsApp через [`whatsapp.py`](../bots/telegram-search/whatsapp.py) (небольшой вебхук на `127.0.0.1`).
- **Состояние**: Redis (история, память, напоминания, слежения).
- **Доступ**: SSH + [Tailscale](https://tailscale.com), `ufw` по умолчанию закрыт. Настройка сервера описана в [`docs/home-server.md`](home-server.md).

## Безопасность, ведь агенту с доступом к оболочке она необходима

- **Приватность**: в Telegram первый, кто отправит `/start`, становится единственным владельцем; в WhatsApp отвечают только номерам из `WA_OWNER`.
  Всех остальных бот игнорирует.
- **Ничего рискованного не происходит молча**: отправка почты, отправка формы, удаление события, запуск команды
  или нажатие кнопки «Купить / Оплатить / Удалить» — всё это сначала требует нажатия **Да / Нет**.
- **Пароли никогда не проходят через модель**: логины для сайтов хранятся в файле с правами `0600` и подставляются обычным кодом.
  Сохранять их можно только в Telegram, потому что бот сразу удаляет ваше сообщение (в WhatsApp оно бы осталось).
- **Веб-страницы — это данные, а не приказы**: текст, найденный на странице или в письме, не может давать агенту указания.
- **Никакой локальной сети через браузер**: разрешены только публичные адреса `http(s)` (защита от SSRF).
- **Секретов в этом репозитории нет**: ключи хранятся в `.env` на сервере.

## Быстрый старт

Вам понадобятся Linux-машина, Python 3, Redis, **токен Telegram-бота** (от [@BotFather](https://t.me/BotFather)) и один
**API-ключ** любого из перечисленных выше провайдеров (у Groq есть бесплатный тариф).

```bash
git clone https://github.com/LdwS123/Instonct.git && cd Instonct
sudo apt install redis-server python3-venv espeak-ng mpv alsa-utils      # голос + музыка (необязательно)
python3 -m venv ~/bots/venv && ~/bots/venv/bin/pip install -r bots/telegram-search/requirements.txt
mkdir -p ~/bots/telegram-search && cp bots/telegram-search/*.py ~/bots/telegram-search/

cat > ~/bots/.env <<'EOF'
TELEGRAM_TOKEN=...
LLM_API_KEY=...
# необязательно: LLM_BASE_URL, LLM_MODELS, GEMINI_API_KEY, STT_LANGUAGE=en, WA_* (WhatsApp)
EOF
chmod 600 ~/bots/.env

sudo cp systemd/bot-telegram.service /etc/systemd/system/    # сначала отредактируйте User= и пути
sudo systemctl daemon-reload && sudo systemctl enable --now bot-telegram
```

Затем откройте своего бота в Telegram и отправьте `/start`. Необязательно: Lightpanda в `~/lightpanda/lightpanda` для
браузера, `MAIL_USER` / `MAIL_PASS` / `MAIL_HOST` для почты и `scripts/google-auth.py` для Google Календаря.
