> **Instinct AI या Spear Street Technology से कोई संबंध नहीं।** "Instinct" उसके मालिक का है।
> Instonct एक स्वतंत्र शौकिया प्रोजेक्ट है। यह नाम जान-बूझकर रखा गया एक व्यंग्य (पैरोडी) है, और यह पेज
> इसकी तुलना Instinct AI से केवल इसलिए करता है ताकि विकल्प ढूँढ रहे लोग इसे खोज सकें।

---

**Instonct** एक ओपन-सोर्स, सेल्फ-होस्टेड **निजी AI एजेंट** है। आप इसे **WhatsApp या Telegram** पर मैसेज करते हैं
(टेक्स्ट या वॉइस नोट) और यह काम कर देता है: आपका मेल पढ़ता है और उसके ड्राफ़्ट लिखता है, आपका Google Calendar संभालता है, रिमाइंडर
और टू-डू सेट करता है, ब्राउज़ करता है और वेब फ़ॉर्म भरता है, किसी पेज को CSV में स्क्रैप कर देता है, किसी पेज पर नज़र रखता है और बदलाव होते ही
आपको बता देता है, संगीत बजाता है, यहाँ तक कि जिस मशीन पर चल रहा है उस पर शेल कमांड भी चलाता है।

यह **2010 के Mac mini** (Core 2 Duo, 4.6 GB RAM, Lubuntu) पर 24x7 चलता है। अगर यह वहाँ चलता है, तो यह लगभग
हर चीज़ पर चलेगा: Raspberry Pi, कोई पुराना लैपटॉप, या सस्ता VPS।

## यह क्या-क्या कर सकता है

| क्षेत्र | आप क्या कह सकते हैं |
|---|---|
| **मेल** | "आज कोई ज़रूरी मेल आया?", "Paul को जवाब दो कि मैं आ रहा हूँ।" मेल तभी भेजता है जब आप **Yes** दबाते हैं। |
| **कैलेंडर** | "गुरुवार को दोपहर 3 बजे डेंटिस्ट डाल दो", "Marie के साथ एक Google Meet जोड़ दो।" टकराव होने पर चेतावनी देता है। |
| **ब्राउज़र** | "news.ycombinator.com पर जाओ और टॉप 30 शीर्षकों की CSV दो", "मुझे मेरी जिम की साइट में लॉग इन कर दो।" |
| **निगरानी** | "जब यह पेज *in stock* दिखाए तो बताना।" हर 10+ मिनट में जाँचता है, सिर्फ़ बदलाव होने पर ही सूचना देता है। |
| **याददाश्त** | आपकी पसंद-नापसंद हमेशा के लिए याद रखता है, और आपके सुधारने पर सीखता है। |
| **रूटीन** | सुबह की ब्रीफ़िंग (एजेंडा, मेल, मौसम, आपकी नंबर 1 प्राथमिकता), रिमाइंडर, शेड्यूल किए गए काम। |
| **आवाज़** | वॉइस नोट सुनकर समझता है (Whisper), जवाब में वॉइस नोट या बोला हुआ उत्तर भेजता है। |
| **फ़ाइलें** | इसे कोई फ़ोटो, PDF या CSV भेजें और उसके बारे में पूछें। यह फ़ाइलें वापस भी भेज सकता है। |
| **घर** | संगीत, TV रिमोट, वॉल्यूम, सर्वर की सेहत, शेल कमांड (पुष्टि के बाद)। |
| **कोई भी भाषा** | आप जिस भाषा में लिखते या बोलते हैं, यह उसी में जवाब देता है। |

इसका एक व्यक्तित्व भी है: छोटे जवाब, एक साफ़ सुझाव, बेवजह की बातें नहीं। इसका नाम *Steve* है।

## अपना "दिमाग" चुनें: कोई भी मॉडल, कोई भी प्रोवाइडर

Instonct किसी भी **OpenAI-संगत API** से बात कर सकता है, इसलिए आप किसी एक कंपनी से बँधे नहीं हैं। `.env` में बस तीन लाइनें सेट करें:

```bash
LLM_BASE_URL=https://api.groq.com/openai/v1     # डिफ़ॉल्ट
LLM_API_KEY=...
LLM_MODELS=openai/gpt-oss-120b,openai/gpt-oss-20b,qwen/qwen3.8-27b    # इसी क्रम में आज़माए जाते हैं
```

| प्रोवाइडर | `LLM_BASE_URL` |
|---|---|
| Groq (डिफ़ॉल्ट, तेज़, फ़्री टियर) | `https://api.groq.com/openai/v1` |
| OpenRouter (सैकड़ों मॉडल) | `https://openrouter.ai/api/v1` |
| OpenAI | `https://api.openai.com/v1` |
| Together AI | `https://api.together.xyz/v1` |
| Mistral | `https://api.mistral.ai/v1` |
| Cerebras | `https://api.cerebras.ai/v1` |
| Ollama / LM Studio (100% लोकल, कोई की (key) नहीं) | `http://localhost:11434/v1` |

मॉडल के नाम ठीक वैसे ही लिखें जैसे आपका प्रोवाइडर लिखता है, और ऐसे मॉडल चुनें जो टूल कॉलिंग को सपोर्ट करते हों।

- **चलते-चलते बदलें**: सूची देखने के लिए `/model` भेजें, नंबर 2 को पहले इस्तेमाल करने के लिए `/model 2`, और वापस जाने के लिए `/model auto`।
- **अपने-आप फ़ॉलबैक**: अगर कोई मॉडल रेट-लिमिट में आ जाए या बंद हो, तो अगला मॉडल अपने-आप काम संभाल लेता है।
- **वैकल्पिक सुरक्षा कवच**: `GEMINI_API_KEY` जोड़ें, तो आपका मुख्य प्रोवाइडर बंद होने पर Google Gemini जवाब देता है (और तस्वीरें भी पढ़ता है)।
  इसके बिना भी Instonct एक ही प्रोवाइडर पर बढ़िया चलता है।
- **वॉइस नोट**: Whisper API से ट्रांसक्राइब होते हैं (`STT_MODEL`, `STT_BASE_URL`, `STT_LANGUAGE`, डिफ़ॉल्ट रूप से वही प्रोवाइडर)।

## WhatsApp या Telegram?

दोनों काम करते हैं, एक ही समय पर, एक ही दिमाग, याददाश्त और सुरक्षा नियमों के साथ।

| | Telegram | WhatsApp |
|---|---|---|
| सेटअप | @BotFather के साथ 2 मिनट | Meta डेवलपर अकाउंट, एक नंबर, एक टोकन (लगभग 30 मिनट) |
| सार्वजनिक पता चाहिए | नहीं (बॉट खुद बाहर कॉल करता है) | हाँ (Meta आपके सर्वर को कॉल करता है: Tailscale Funnel काम करता है) |
| Yes / No बटन, वॉइस, फ़ाइलें | हाँ | हाँ |
| TV रिमोट कीबोर्ड, `/site` से पासवर्ड सेव करना | हाँ | केवल Telegram पर (जान-बूझकर, देखें सुरक्षा) |
| बॉट द्वारा अपनी ओर से भेजे गए मैसेज (रिमाइंडर) | हमेशा | केवल आपके आख़िरी मैसेज के 24 घंटे के भीतर |
| पहले से आपके फ़ोन में है | शायद | लगभग पक्का |

**ईमानदार सलाह**: Telegram से शुरू करें, यह ज़्यादा सरल और सुरक्षित है। जब आप इससे उसी ऐप पर बात करना चाहें जिसे आप
रोज़ इस्तेमाल करते हैं, तब WhatsApp जोड़ें। Instonct Meta के **आधिकारिक WhatsApp Cloud API** का इस्तेमाल करता है, किसी अनौफ़िशियल लाइब्रेरी का कभी नहीं, इसलिए
आपके नंबर के बैन होने का कोई जोखिम नहीं है।

### WhatsApp जोड़ें (वैकल्पिक)

1. [developers.facebook.com](https://developers.facebook.com) पर एक ऐप बनाएँ, **WhatsApp** प्रोडक्ट जोड़ें, और
   **Phone number ID** नोट कर लें। आज़माने के लिए मुफ़्त टेस्ट नंबर चलता है; बाद में आप अपना नंबर जोड़ सकते हैं।
2. एक स्थायी एक्सेस टोकन बनाएँ (Meta Business सेटिंग्स में *System User* टोकन) और **App secret** कॉपी करें
   (App settings, Basic)।
3. `~/bots/.env` में जोड़ें (आपका अपना नंबर: केवल अंक, पहले देश कोड, `+` नहीं):
   ```bash
   WA_TOKEN=...
   WA_PHONE_ID=...
   WA_APP_SECRET=...
   WA_VERIFY_TOKEN=any-secret-string-you-invent
   WA_OWNER=33612345678
   ```
4. लोकल वेबहुक (पोर्ट 8088, `127.0.0.1` से बँधा) के लिए Meta को एक सार्वजनिक HTTPS पता दें। Tailscale के साथ:
   `sudo tailscale funnel --bg 8088`। यह एक `https://<machine>.<tailnet>.ts.net` पता प्रिंट करता है।
5. अपने Meta ऐप की WhatsApp सेटिंग्स में, वेबहुक का **Callback URL** उसी पते पर और **Verify token**
   अपने `WA_VERIFY_TOKEN` पर सेट करें, फिर **messages** फ़ील्ड को सब्सक्राइब करें।
6. बॉट को रीस्टार्ट करें (`sudo systemctl restart bot-telegram`) और अपने WhatsApp नंबर पर मैसेज करें।

हर आने वाली कॉल अस्वीकार कर दी जाती है जब तक उसका `X-Hub-Signature-256` आपके ऐप सीक्रेट से मेल न खाए, और केवल
`WA_OWNER` में दिए गए नंबरों को ही जवाब मिलता है। Meta के डैशबोर्ड के लेबल समय-समय पर बदलते रहते हैं; बात वही रहती है।
API वर्ज़न डिफ़ॉल्ट रूप से `v23.0` है; अगर Meta इसे बंद कर दे तो `WA_API_VERSION` से इसे बदल दें।

## Instinct AI vs Instonct

| | Instinct AI | Instonct |
|---|---|---|
| एक्सेस | केवल इन्वाइट से (प्रेस कवरेज के अनुसार) | रेपो क्लोन करें और चलाएँ |
| कहाँ चलता है | किसी कंपनी के क्लाउड में | **आपकी अपनी मशीन पर** |
| आपका डेटा | एक स्टार्टअप को सौंपा जाता है | आपके अपने बॉक्स पर रहता है (Redis + लोकल फ़ाइलें) |
| आप इससे कैसे बात करते हैं | टेक्स्ट, फ़ोन, WhatsApp (प्रेस कवरेज के अनुसार) | WhatsApp या Telegram, टेक्स्ट या वॉइस |
| मॉडल | आपके लिए पहले से चुने हुए | **कोई भी OpenAI-संगत प्रोवाइडर**, `/model` से बदलें |
| लागत | सार्वजनिक नहीं | फ़्री टियर चलते हैं (Groq, Gemini); या Ollama के साथ पूरी तरह लोकल |
| सोर्स कोड | बंद | **यहीं मौजूद है** |

Instinct AI फ़ंडिंग वाली टीम का बनाया एक असली प्रोडक्ट है; Instonct एक अकेले इंसान का वीकेंड प्रोजेक्ट है जो अब रोज़ का साथी बन गया है।
अगर आप वही विचार चाहते हैं पर स्टीयरिंग अपने हाथ में रखकर, तो Instonct चुनें।

## यह कैसे काम करता है

- **दिमाग**: कोई भी OpenAI-संगत मॉडल (डिफ़ॉल्ट रूप से Groq `gpt-oss-120b` / `20b`, अनुकूली रीज़निंग एफ़र्ट के साथ), वैकल्पिक Gemini फ़ॉलबैक।
- **टूल**: मॉडल लगभग 35 टूल कॉल करता है (मेल, कैलेंडर, ब्राउज़र, फ़ाइलें, संगीत, TV, शेल...)। देखें [`catalog.py`](../bots/telegram-search/instonct/catalog.py) में `TOOLS`।
- **ब्राउज़र**: [Lightpanda](https://github.com/lightpanda-io/browser), एक छोटा-सा हेडलेस ब्राउज़र (~25 MB RAM) जो 2010 के CPU पर भी चल जाता है। देखें [`webagent.py`](../bots/telegram-search/instonct/webagent.py)।
- **चैनल**: Telegram लॉन्ग पोलिंग से (कोई पोर्ट खुला नहीं), WhatsApp [`whatsapp.py`](../bots/telegram-search/instonct/whatsapp.py) के ज़रिए (`127.0.0.1` पर एक छोटा-सा वेबहुक)।
- **स्थिति (State)**: Redis (हिस्ट्री, याददाश्त, रिमाइंडर, निगरानी)।
- **पहुँच**: SSH + [Tailscale](https://tailscale.com), `ufw` डिफ़ॉल्ट रूप से बंद। सर्वर सेटअप [`docs/home-server.md`](home-server.md) में है।

## सुरक्षा, क्योंकि शेल वाले एजेंट को इसकी ज़रूरत है

- **निजी**: Telegram पर `/start` भेजने वाला पहला व्यक्ति ही एकमात्र मालिक बन जाता है; WhatsApp पर केवल `WA_OWNER` में दिए गए नंबरों को
  जवाब मिलता है। बाकी सबको नज़रअंदाज़ कर दिया जाता है।
- **कोई जोखिम भरा काम चुपचाप नहीं होता**: मेल भेजना, फ़ॉर्म सबमिट करना, इवेंट डिलीट करना, कमांड चलाना
  या "Buy / Pay / Delete" बटन पर क्लिक करना, इन सबसे पहले **Yes / No** दबाकर पुष्टि माँगी जाती है।
- **पासवर्ड कभी मॉडल से होकर नहीं गुज़रते**: साइट के लॉगिन एक `0600` फ़ाइल में सहेजे जाते हैं और सादा कोड उन्हें भरता है।
  इन्हें सेव करना केवल Telegram पर संभव है क्योंकि बॉट आपका मैसेज तुरंत बाद डिलीट कर देता है (WhatsApp उसे रख लेता)।
- **वेब पेज डेटा हैं, आदेश नहीं**: किसी पेज या मेल में मिला टेक्स्ट एजेंट को निर्देश नहीं दे सकता।
- **ब्राउज़र के ज़रिए लोकल नेटवर्क तक पहुँच नहीं**: केवल सार्वजनिक `http(s)` पतों की अनुमति है (SSRF गार्ड)।
- **सीक्रेट कभी इस रेपो में नहीं**: की (key) सर्वर पर एक `.env` फ़ाइल में रहती हैं।

## क्विक स्टार्ट

आपको चाहिए: एक Linux बॉक्स, Python 3, Redis, एक **Telegram बॉट टोकन** ([@BotFather](https://t.me/BotFather) से) और ऊपर दिए किसी भी प्रोवाइडर की एक
**API की** (Groq का फ़्री टियर है)।

```bash
git clone https://github.com/LdwS123/Instonct.git && cd Instonct
sudo apt install redis-server python3-venv espeak-ng mpv alsa-utils      # वॉइस + संगीत (वैकल्पिक)
python3 -m venv ~/bots/venv && ~/bots/venv/bin/pip install -r bots/telegram-search/requirements.txt
mkdir -p ~/bots/telegram-search && cp -r bots/telegram-search/bot.py bots/telegram-search/instonct ~/bots/telegram-search/

cat > ~/bots/.env <<'EOF'
TELEGRAM_TOKEN=...
LLM_API_KEY=...
# वैकल्पिक: LLM_BASE_URL, LLM_MODELS, GEMINI_API_KEY, STT_LANGUAGE=en, WA_* (WhatsApp)
EOF
chmod 600 ~/bots/.env

sudo cp systemd/bot-telegram.service /etc/systemd/system/    # पहले User= और पाथ बदलें
sudo systemctl daemon-reload && sudo systemctl enable --now bot-telegram
```

फिर Telegram में अपना बॉट खोलें और `/start` भेजें। वैकल्पिक: ब्राउज़र के लिए `~/lightpanda/lightpanda` में Lightpanda,
मेल के लिए `MAIL_USER` / `MAIL_PASS` / `MAIL_HOST`, और Google Calendar के लिए `scripts/google-auth.py`।
